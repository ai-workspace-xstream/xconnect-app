# 托管连接的离线缓存

托管节点的配置文件和 SQLite 节点记录继续使用现有本地存储。成功完成一次
完整同步后，应用另外保存该快照对应的访问策略，按服务地址和登录账号隔离，
使相同账号重启应用后遇到断网、超时或服务端 5xx 时仍可恢复最近的有效节点。
非空但结构不完整的节点响应不再作为空列表清除本地配置。

缓存有效期为最后一次完整同步后的 24 小时与团队有效期中较早的一项。
退出登录、切换账号或服务地址、明确的 401/403、访问策略拒绝及权威空节点
列表会使缓存失效。服务器确认账号/团队范围或有效期变更时，旧快照也不能在
下一次离线启动时恢复；新范围必须完成一次成功同步。

## 停用与清空分离

- 断网、超时、5xx 和格式错误保留最近的完整快照，在上述授权有效期内继续使用。
- 登录失效、退出登录、普通授权失败、空节点列表及授权到期，只撤销使用权限，
  不删除本地配置文件或 SQLite 节点记录。停用的节点不会出现在可用连接列表中，
  保留文件不等于允许绕过登录或账号授权。
- 重新登录或切换账号成功后自动同步。切换期间旧配置保留但不可使用；只有新账号
  的非空、有效快照成功落盘后才替换并清理旧账号托管节点，不混用账号配置。
- 彻底清空只接受服务端明确的套餐停流、流量停止或黑名单机器码。HTTP 403、
  错误说明文字、空列表和套餐内额度为零本身，都不能作为删除依据。
- 自定义导入始终独立，不受以上托管清理影响。

目前清空白名单为 `quota_exhausted`、`traffic_quota_exceeded`、`quota_exceeded`、
`traffic_stopped` 和 `email_blacklisted`，从 JSON 的 `code` / `error` / `reason`
读取；仅在 403、429，或 200 且 `allowed: false` 的明确拒绝响应中生效。
未知拒绝码不授权删除。清理按已确认的账号归属执行；新账号尚未确认归属就被拒绝时，
不会误删前一个账号保留的文件。账号归属绑定不授予任何访问权限。

策略缓存只保存账号范围、节点标识、授权范围及有效期，不额外保存会话令牌、
密码、私钥或连接 URI；连接配置仍只由现有配置存储管理。升级后需要在线成功
同步一次才能生成新策略缓存，不能根据旧节点文件推测授权。

此改动不调整节点 DNS、NetworkExtension 生命周期、自动重连或默认节点。
能加载缓存不代表目标服务器可达，实际 VPN 连接仍需单独验证。
